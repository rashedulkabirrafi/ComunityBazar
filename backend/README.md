# ComunityBazar backend

Express/MongoDB API for ComunityBazar.

- `index.js` — the API: authentication, listings, cart, wishlist, orders, reviews and uploads.
- `firebase.json` — local Firebase Authentication emulator configuration.
- `scripts/` — local stack tooling: `setup-local.mjs`, `start-local.mjs`, `stop-local.mjs` and
  `seed-local.mjs`. Run them through the root commands (`npm run setup`, `npm start`, `npm stop`,
  `npm run seed`).

See the [project guide](../README.md), the [frontend](../frontend/Readme.md) and the
[security suite](../security/README.md).
