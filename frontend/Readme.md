# ComunityBazar frontend

React/Vite frontend for ComunityBazar.

- `src/pages/` — routed pages, `src/components/` and `src/ui/` — shared interface pieces.
- `src/lib/api.js` and `src/config/api.js` — API access and its base URL.
- `scripts/build-production.mjs` — production build helper.

Run it through the root commands (`npm start` for the whole stack, or `npm run dev --prefix
frontend` for the interface alone against a running API).

See the [project guide](../README.md), the [backend](../backend/README.md) and the
[security suite](../security/README.md).
